# To-Do-List
This project is a simple yet functional To-Do List application built using HTML, CSS, and JavaScript. It allows users to keep track of tasks they need to complete by adding, editing, deleting, and marking them as done. The user interface is clean and responsive, offering a seamless experience across devices.

Features:
Add Tasks: Users can input and add new tasks to the list.

Delete Tasks: Tasks can be removed individually.

Mark as Completed: Click on a task to mark it as done (with a visual change).

Persistent Storage (Optional): Tasks can be saved in localStorage so they remain after the page is reloaded.

Responsive Design: The layout adapts well on both desktop and mobile screens.

Technologies Used:
HTML: For the structure of the application.

CSS: For styling the interface and making it visually appealing.

JavaScript: For dynamic interactions like adding or removing tasks and updating task status.
